> ╰┈➤ Simplicity works 

## What is it? 🤔💭
A simple to use yet complete FOSS art software, you might ask yourself

"What is FOSS?"

It stands for "Free and Open Source Software"

That means people 

- Truly own it
- Can modify it

And etc!

## Why do i make this? 👀💡
To help artist finding 

- Alternatives yet
- Easy to use and complete art software

I also made this software so that coders/developers can colaborate with artist!

## List of commands >_📝
- Ctrl z and y (undo and redo)
- Escape (closing pop up)
- Ctrl x (save drawings)
